Clock. Python Tutorials. TUI. Curses Library. Simple Input/Output. Console Application. 
The program does the following:
  1. Loads the Curses library.
  2. Creates a standard terminal size window (80 columns, 25 rows).
  3. Clears the created window.
  4. Displays a label with the current time in the format "hours:minutes:seconds" in 1 column and 1 row.
  5. Pauses execution for 1 second.
  6. Waiting for a key to be pressed.
  7. Repeats steps 4,5,6. If a key is pressed goes to step 8.
  8. Unloads the Curses library and exits.

Clock. Занятия по Python. Приложение с текстовым интерфейсом пользователя. Библиотека Curses. Простой ввод-вывод. Консольное приложение.
Программа делает следующее:
  1. Загружает библиотеку Curses.
  2. Создаёт окно стандартного размера терминала (80 столбцов, 25 строк).
  3. Очищает созданное окно.
  4. Выводит на экран надпись с текущим временем формата "часы:минуты:секунды" в 1 столбце и 1 строке.
  5. Приостанавливает на 1 секунду выполнение.
  6. Ждёт нажатия клавиши.
  7. Повторяет шаги 4,5,6. Если нажата клавиша, переходит к шагу 8.
  8. Выгружает библиотеку Curses и завершает работу.
